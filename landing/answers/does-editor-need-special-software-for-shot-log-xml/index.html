Compatibility

Does the editor need special software to open a shot log's Premiere XML?

No plugin, no paid utility. The Premiere export is a standard legacy FCP7 xmeml file, the same XML dialect Premiere Pro has always read natively through File > Import or a straight drag into a project bin. Any editor with Premiere already installed can open it. The one thing they will need to do afterward is relink the media, either automatically because a footage root was set, or by hand with locate then relink others by file name.

What is inside the file

A marker on every clip at the exact frame something was tagged, named from the shot code, the tag, and the label. A two-band timeline structure: good takes back to back in story order first, then every take again, good and rejected, as a selects pool past a short gap. If the shoot was multi-camera, each unit's picture and audio ride their own synced track pair, already aligned to the same take position across cameras. None of this needs a plugin to read, because it is all standard sequence, clip, and marker XML that Premiere's own importer already understands. The full mechanics are on the shot log to Premiere XML page.

  1. Drag the file in

    Drop the exported .xml into a Premiere project bin, or use File > Import. No conversion step, no third-party importer.

  2. It lands as a new sequence

    The sequence carries the project's name, with markers already on the clips and every clip referencing the card's native file name.

  3. Locate one clip, then relink the rest

    Choose relink others automatically by file name, which brings the whole card online in one pass if no footage root was set ahead of time.

What it does not need: a third-party marker importer, a re-encode of the footage, or any plugin installed in Premiere. It is a file Premiere already knows how to read, the same way it has always read an FCP7 sequence handed off from any other tool.
