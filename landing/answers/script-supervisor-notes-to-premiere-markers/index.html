Set notes to editor

How do you get script supervisor notes into Premiere as markers?

There is no built-in Premiere feature that reads a PDF or paper continuity log and creates markers from it. The notes have to exist in a structured, timecoded file first, matched to the right clip, before Premiere can turn them into anything. Doing that by hand means retyping every note against a clip name after the fact. Doing it with a phone-first take log means the structured file already exists the moment you call wrap, because every note was captured at the moment it happened.

Why "just import the report" does not work

A script supervisor's daily report is built to be read on a page: scene, take, camera roll, a remarks column. That shape is for a human eye, not a marker schema, and Premiere has no reader for it. Third-party CSV marker importers do exist for Premiere, built by people who ran into exactly this gap, but they still expect a structured row per marker with a timecode and a target clip, which a report was never built to provide on its own.

So the real work is upstream of Premiere entirely: getting the notes into a structured, timecoded, per-clip shape in the first place. That is either a manual transcription pass after wrap, or a log that was already structured the moment each note was taken.

  1. Log notes at the moment of the take

    Tag coverage, beats, and the keeper as they happen, with a timecode stamped on each tap, instead of writing free-text notes to reconcile with a clip later.

  2. Flag the keeper as you go

    Mark the circle or GOLD take when the director calls it, not after the fact from memory. A flag that survives to the edit has to be recorded at the moment it is made.

  3. Export a structured file at wrap

    A Premiere XML built from the logged takes carries markers already placed at the exact frame each note happened, named from the shot code, the tag, and the label.

  4. Import the XML into Premiere

    Drag the exported file into a project bin, or use File > Import. It lands as a new sequence, markers already on the clips.

  5. Relink the footage

    Locate one clip by hand, then choose relink others automatically by file name, which brings the rest of the shoot online in one pass.

What this replaces: an assistant editor with the paper report on one monitor and the timeline on the other, scrubbing to a take number and typing a marker by hand, one clip at a time. It works. It also does not scale past a short day's footage without someone losing an hour to it.

The mechanics of what actually rides on each marker, how a multi-camera sequence gets built, and why a good take does not duplicate the media bin are covered in depth on the shot log to Premiere XML page. This page is about the step before that: getting from notes to a file Premiere can read at all.
