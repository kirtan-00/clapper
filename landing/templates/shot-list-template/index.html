What a shot list is

A shot list is the plan for every shot a scene needs, made before the day so the crew isn't inventing coverage on set. It breaks a scene into its wide, its coverage, and its inserts, with a size and a movement for each, so the whole crew is shooting the same plan instead of guessing at it between setups.

Get it wrong and a fast day eats coverage you needed for the cut. Get it right and the 1st AD can see exactly what's left to get at a glance, and the edit has options instead of gaps.

What is on the sheet

  • SceneThe scene number, so the list lines up with the script.
  • Shot #The shot number within the scene, in the order you plan to get it.
  • SizeWS, MS, CU, or whatever shorthand your crew uses.
  • MovementStatic, handheld, push in, pan, whatever the shot calls for.
  • DescriptionOne line, specific enough that someone else could shoot it from the sheet alone.
  • LensThe focal length, if the shot is planned around one.
  • StatusA box to check the moment the shot is in the can.
  • NotesAnything the next unit or the edit needs to know about the shot.

How a pro fills it in

  1. Break the scene into shots

    Read the scene and list every shot you plan to get: the establishing wide, the coverage, the inserts. One row per shot.

  2. Set the size and movement

    Note the size and any camera movement so the operator knows the frame before you roll.

  3. Write the description

    One line, specific enough to shoot from the sheet alone if you're not the one who wrote it.

  4. Note the lens

    Write the lens if the shot is planned around one, so the AC has it ready before the setup.

  5. Mark it off as you get it

    Check the status box the moment the shot is in the can, so the AD can see coverage left without asking.

When to use it

Build one sheet per scene during prep, from the script or a scout, then bring it to set and run it live. It works for a short film, a feature, a spec, a student project, or a branded shoot with a locked board. Update it as the day changes, not after wrap, so it stays the thing the 1st AD actually checks coverage against.
