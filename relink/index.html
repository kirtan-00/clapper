Clapper Relink

Rewrites the media paths inside a Premiere / FCP7 XML so the whole shoot relinks in one step — through the SD-card and day folders the footage actually sits in — instead of being hunted down clip by clip.

Your files never leave this machine. Everything here runs in this browser tab — no upload, no server, no network request. Close the wifi and it still works.

01Load the XML

Drop the exported XML here, or click to browse.

02Give it a destination

A — where the folder will live

The path to the project folder on the machine you will edit on. Windows (E:\folder\project) or POSIX (/Volumes/Drive/project). The browser is never told where a folder really is, so this one line is yours to type.

B — the folder itself

Point at that same folder here and the tool walks every subfolder inside it — SD CARD 1/DAY-1 and the rest — then writes each clip's real path. Without this it can only write one flat folder, and nested footage stays offline.
